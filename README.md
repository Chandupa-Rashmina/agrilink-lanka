# AgriLink Lanka

AgriLink Lanka is a full-stack agricultural platform built as a monorepo.

## Applications

- `apps/api` — Laravel REST API
- `apps/web` — Nuxt web application
- `apps/mobile` — Flutter mobile and desktop application

## Platform

- PostgreSQL for relational data
- Redis for queues and caching
- Docker Compose for repeatable environments
- GitHub Actions for CI/CD

## Current Status

The repository foundation and development environment are being prepared.
